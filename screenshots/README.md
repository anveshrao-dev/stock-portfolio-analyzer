# Screenshots

This directory is reserved for actual application captures. Use only the built-in
synthetic datasets and the labeled offline reference price mode; never capture
personal brokerage data or credentials.

Suggested captures using the sample files:

- `transactions.png`: a validated sample preview with accepted/rejected counts.
- `portfolio.png`: separate currency totals and a consolidated holdings table.
- `risk-simulator.png`: a hypothetical −20% scenario with its baseline and impact.
- `history.png`: lifetime metrics and annualized returns with the valuation date.
